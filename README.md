# WAWE — Школа серфинга (Landing Page)

Адаптивный сайт для школы серфинга.

## 🛠 Технологический стек

- **HTML5** (семантическая разметка, формы обратной связи)
* **SCSS / Sass** (переменные, миксины, вложенность, компиляция в CSS)
- **CSS3** (Flexbox, CSS Grid, позиционирование, адаптивные медиа-запросы)
- **JavaScript (ES6+)** (интерактивность интерфейса и навигации)

## 🚀 Локальный запуск

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com
    ```

2. **Откройте проект:**
   Откройте файл `index.html` в браузере или запустите проект через **Live Server** в VS Code.
